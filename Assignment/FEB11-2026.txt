1.Write an SQL query to display the student_id, subject, and marks of students 
who scored more than 80 marks in any subject, ordered by marks in descending order.

/*
SELECT → chooses columns to display
FROM Marks → table name
WHERE marks > 80 → filters students scoring above 80
ORDER BY marks DESC → highest marks shown first
*/

SELECT student_id, subject, marks FROM Marks WHERE marks > 80 ORDER BY marks DESC;

7. Write an SQL query to display the student_id and total marks of students whose total marks are greater 
than the average total marks of all students, using a subquery.

SELECT student_id, SUM(marks) AS total_marks
FROM Marks
GROUP BY student_id
HAVING SUM(marks) > (
    SELECT AVG(total_marks)
    FROM (
        SELECT SUM(marks) AS total_marks
        FROM Marks
        GROUP BY student_id
    ) AS temp
);

8. Write an SQL query to find the student_id and average marks of students whose average marks are greater 
than the overall average marks of all students, using a subquery.

SELECT student_id, AVG(marks) AS avg_mark

GROUP BY student_id

9. Write an SQL query to display the department name and number of students in each department, 
but include only those departments that have at least three students who have marks recorded, 
without using JOIN.


SELECT department, COUNT(*) AS num_of_student_per_dept
FROM Students
WHERE student_id IN(SELECT DISTINCT student_id FROM Marks)
GROUP BY department
HAVING COUNT(*) >= 3;
